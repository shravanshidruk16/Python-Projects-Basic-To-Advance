# 100+ Python Projects From Scratch to Advance 🥇🐎

A high-intensity, 6-month roadmap designed to master Python through 100 hands-on projects where each phase contains 10-20 projects based on difficulty level . This journey moves from basic Command Line Interface (CLI) tools to advanced Web Scraping, GUI applications, Data Analysis, Cloud Deployment and Machine Learning Projects.

> **Challenge Mantra:** *"Write every line. Debug every line , Improve every line , Document every step. Commit every day."*

## 🛠 The Rules of Engagement (DevDiscipline)
To ensure maximum learning and engineering discipline, I am following these five core mandates:

1. **Atomic Structure**: Every project has its own dedicated folder.
2. **Mandatory Documentation**: Every project includes a specific `README.md` file.
3. **GitHub Streak**: Daily commits to maintain a consistent public proof of work.
4. **Zero AI Policy**: No use of LLMs (ChatGPT, Claude, etc.) for code generation or debugging. Only official documentation and pure logic with try and error methods.
5. **180-Day Deadline**: Completing minimum 100 projects within 6 months.
6. **New Learnings & Implementations**: Each and Every Project I build is used by me in my Daily-Life . When you have a clear **WHY** of doing something everyday , everything else will be easy to implement

## 🗺️ Roadmap Overview

* **Phase 1: The Basics & CLI** (Projects 1–10) - Focus on logic, loops, and file I/O.
* **Phase 2: Web Scraping & Automation** (Projects 11–20) - Focus on interacting with the web.
* **Phase 3: GUI & Web Fundamentals** (Projects 21–30) - Focus on frontend and APIs.
* **Phase 4: Intermediate Web & Data** (Projects 31–40) - Focus on databases and analysis.
* **Phase 5: Advanced & Deployment** (Projects 41–50) - Focus on ML, Docker, and Cloud.
* **AND MUCH MORE PHASES** - Stay tuned .
